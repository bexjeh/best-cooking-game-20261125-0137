Sizzle & Serve — a complete burger cooking game that plays offline in a desktop browser. You run the Burger Barn lunch shift: read the order board, grill patties on the stove, stack each burger in recipe order on the pass, and serve before customers lose patience. Fast serves earn tips, clean streaks build a combo multiplier, and the last 30 seconds turn into a full rush hour.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network, just static files under `game/`. Click an ingredient bin or press 1–6 to stack it, Space to serve, T to trash a bad plate, P to pause, R to restart.
